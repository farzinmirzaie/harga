# harga

Static web app that compares Malaysian grocery prices from KPDN PriceCatcher data, parsed in the browser. No backend, no build step.

## Critical commands

```bash
npm test            # unit tests (offline); CI runs this
npm run test:live   # plus a real PriceCatcher download
npm start           # http://localhost:4173
npm run images      # regenerate product photos (needs review, see README)
```

## Architecture

- `index.html`: markup and all CSS. Design tokens (colour, radius, control height, motion) sit at the top of the stylesheet.
- `app.js`: UI. Loads hyparquet from jsdelivr by dynamic `import()` inside `load()`, so the page shell paints before the CDN responds.
- `harga.js`: pure logic, no DOM. Anything with branches belongs here with a test in `harga.test.mjs`.
- `i18n.js`, `items.js`, `districts.js`: data modules. `images.js` and `img/` are generated by `tools/match-images.mjs`.
- Deploy: `.github/workflows/pages.yml` publishes `index.html`, every root `*.js` and `img/`. A new browser module must live in the root as `*.js`. Tests and tools use `.mjs` or live in `tools/` so they are not published.

## Required rules

- Keep it static. Use relative URLs only: the site is served from a GitHub Pages sub-path.
- Every UI string goes in `i18n.js` in all three languages (en, ms, zh). Item names fall back to the official Malay name.
- Use the existing button classes and tokens. Every clickable element is a pill with a hover state, a `:active` scale of .95 and a height of `--h-sm`, `--h-md` or `--h-lg`. Use the motion tokens `--d-*`, `--ease-*` and `--spring`, not raw durations.
- Basket edits call `basketChanged()`, which updates only the basket and the affected card buttons. Do not re-render the item grid for them: it flashes and replays the entrance animation.
- Close dialogs with `closeDialog()` so the exit animation runs. Esc and backdrop clicks already route there.
- Accessibility: icon-only buttons need a translated `aria-label` that names the item. All motion must stop under `prefers-reduced-motion`. After UI changes, run axe-core in the page (WCAG 2.2 AA plus best-practice) in light mode, dark mode and with a dialog open. All three are currently clean.
- Product photos: never hotlink Open Food Facts. Every match goes through `tools/review.json`, and the footer and popup credit stays.
- Do not put personal contact details in the code. The Open Food Facts user agent uses the repo URL, or `OFF_CONTACT` if set.

## Data gotchas

- PriceCatcher files: `https://storage.data.gov.my/pricecatcher/pricecatcher_YYYY-MM.parquet` plus `lookup_item.parquet` and `lookup_premise.parquet`. CORS is open. The current month returns 404 until KPDN publishes it, and only a 404 falls back to the previous month.
- hyparquet returns INT64 columns as `BigInt` and DATE as `Date`. Convert at the boundary, in `readPrices()`.
- PriceCatcher districts do not match DOSM boundary names: KL has 11 parliamentary areas, and towns like Petaling Jaya are separate districts. `districts.js` holds hand-entered points for those. "Near me" only considers districts that have shops.
- Shop types include restaurants and food courts, because cooked-food prices are also tracked.

## Local preview gotchas

- `python3 -m http.server` lets the browser cache ES modules. After editing a `.js` file, hard-reload, or fetch the file with `{ cache: 'reload' }`.
- Screenshots of a hidden preview pane can show the hero faded, because `requestAnimationFrame` does not run while the pane is hidden. Check `document.documentElement.className` before treating it as a bug.
